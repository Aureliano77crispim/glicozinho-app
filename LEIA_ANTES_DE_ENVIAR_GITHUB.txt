COMO CONFERIR ANTES DE CONFIRMAR O UPLOAD:
1. Extraia este ZIP.
2. Na pasta extraída, selecione e envie TODO o conteúdo, incluindo as pastas .github, app e scripts.
3. Na prévia do GitHub, confirme que aparecem .github/workflows/android-apk.yml e app/build.gradle.kts.
4. Se .github/workflows/android-apk.yml NÃO aparecer na prévia, cancele o upload. Não confirme um envio incompleto.
5. Não envie nenhum arquivo do kit privado de assinatura (.p12, senhas ou Base64 da chave) ao repositório público.

O workflow android-apk.yml é o que gera o APK DEBUG de teste automaticamente ao enviar para a branch main.
O workflow android-release.yml é separado, manual, e só funciona depois de cadastrar os quatro segredos privados descritos no README. Não execute Release agora.

Este pacote não contém APK compilado. O APK só existe depois que a execução GitHub Actions terminar em verde e produzir o artefato.
