COMO ENVIAR
1. Extraia o ZIP.
2. No GitHub, abra o repositório e envie TODO o conteúdo extraído para a branch main, mantendo a estrutura de pastas.
3. Na prévia, confirme especialmente que aparecem `.github/workflows/android-apk.yml`, `app/build.gradle.kts` e `app/src/main/java/br/com/glicozinho/app/`.
4. Confirme o envio. A alteração na branch main inicia o workflow de APK Debug.
5. Abra Actions e acompanhe a execução. Só depois de ficar verde, baixe o artefato `Glicozinho-APK-Debug-v1.0.9`.

NÃO ENVIE SEGREDOS
- Não envie arquivos .p12, .jks, .keystore, senhas ou Base64 da chave de assinatura ao repositório.
- O workflow Release é separado e manual; só será possível usá-lo depois de cadastrar os quatro segredos no GitHub Settings > Secrets and variables > Actions.

IMPORTANTE
- Este pacote contém o código-fonte e os testes, não contém APK compilado.
- A revisão v1.0.9 passou em validação estática, testes de lógica e 50 verificações automatizadas de interface móvel com bridge nativa simulada.
- A compilação real e os testes no Samsung/Android ainda precisam ser concluídos. Consulte `REVISAO_3_PASSAGENS_v1.0.9.md`.
- Não desinstale a versão atual nem apague dados sem exportar e verificar backup.
