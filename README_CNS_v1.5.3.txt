NOVA ALTERAÇÃO — CARTÃO SUS (CNS)

1. Abra Perfil no Glicozinho.
2. Digite opcionalmente os 15 números do Cartão SUS e salve.
3. Na tela Início, o número aparece abaixo da data, ocultando os primeiros dígitos.
4. Toque em Mostrar para revelar temporariamente e em Ocultar para esconder novamente.

A linha não aparece se o CNS não estiver cadastrado. A validação verifica apenas os 15 algarismos; não consulta o SUS.

Para usar esta alteração no Android, envie os arquivos atualizados deste projeto ao repositório GitHub e aguarde o workflow gerar um novo APK. O APK instalado atualmente não recebe a alteração automaticamente.
