Privacidade e backup

No aplicativo Android, os registros locais são criptografados com uma chave protegida pelo Android Keystore. Não existe conta, servidor ou sincronização nesta versão. Os backups são criptografados com uma senha que somente você conhece.

Guarde a senha do backup em local seguro. Sem ela, não será possível restaurá-lo. Para transferir para outro aparelho, envie o arquivo e compartilhe a senha por um canal separado.

🔐 Privacidade

No Android, os registros locais são criptografados no aparelho. Não há transmissão de dados pela internet. A senha do backup é independente do bloqueio do celular. Não compartilhe o aparelho desbloqueado e mantenha o sistema atualizado.

🗑️ Apagar dados deste aparelho

Remove os registros criptografados e os lembretes agendados neste aparelho. Os arquivos de backup exportados para outros locais não são apagados.

ℹ️ Sobre o Glicozinho

Versão beta técnica. O Glicozinho é um organizador de registros e lembretes. Não diagnostica, não interpreta resultados, não prescreve e não calcula doses. Confirme tratamentos e decisões com a equipe de saúde.
